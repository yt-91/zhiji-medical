# 脊护随行 · 脊柱侧弯随访小程序（演示原型）

面向脊柱侧弯患者/家长的随访管理小程序交互原型，1:1 模拟微信小程序形态，覆盖一期至三期全部功能。当前阶段用于产品展示与方案评审。

## 在线演示

通过 GitHub Pages 访问（手机浏览器打开体验最佳）。

## 功能范围

- **报告中心**：筛查报告、Cobb 角趋势图、脊柱曲线示意、PDF/转发
- **随访管理**：自动复查计划、倒计时、时间轴、两次结果并排对比、进展预警
- **居家自查**：四视图拍摄引导（背面/正面/侧面/Adam 前屈位）+ 云端分析模拟
- **预约就诊**：合作医院列表、选医生选号源、预约闭环
- **康复打卡**：训练计划、连续打卡、徽章激励
- **健康科普**：文章列表与详情
- **智能穿戴**（三期）：设备状态、姿势监测趋势、提醒设置
- **消息中心 / 我的**：通知、家庭成员、知情同意、隐私管理

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建 → dist/
```
